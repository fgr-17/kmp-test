Antes de mirar las pantallas

Una revisión automática del trabajo.

Corre sola y deja un informe en un archivo. No hace falta abrir ninguna app.

¿Está escrito parejo?Misma forma en todo el proyecto.
¿Hay fallas conocidas?Busca problemas típicos en la lógica.
¿Hay texto repetido?Marca copias que conviene unir.
¿La lógica responde bien?Preguntas chicas, con un resultado esperado.
¿Cuánto quedó cubierto?Qué parte de la lógica pasó por esas preguntas.
¿La nube cumple el acuerdo?El pedido de ejemplo tiene que salir bien.

El relato, escrito

Las dos escenas que recorren las cuatro pantallas.

Feature: Offline field notes sync As a cellar operator I capture notes while offline and sync them when connectivity returns. Every client app (web, android, ios, desktop) runs this same feature through its own Behave driver. Background: Given the cloud backend is reachable
Sin conexión, la nota queda pendiente
Scenario: Add note while offline stays pending on device
  Given the app is offline
  When I add a note "Checked barrel B12"
  Then I should see a pending note "Checked barrel B12"
  And the cloud should not contain "Checked barrel B12"
Con conexión, la nota llega a la nube
Scenario: Sync pushes pending notes to the cloud
  Given the app is offline
  And I add a note "Checked barrel B12"
  When I go online
  And I sync notes
  Then I should see a synced note "Checked barrel B12"
  And the cloud should contain "Checked barrel B12"

Quién recorre la pantalla

  2. Escribe, marca y sincroniza
Teléfono Android

  2. Lo toca en el centro de ese botón
iPhone
  1. Usa el simulador
  2. Busca el interruptor y los botones
Computadora
  1. Le pide cada paso a la app
  2. La ventana no muestra el mouse

Mirar o no mirar

La misma prueba, con la pantalla oculta o a la vista.

Sin mostrar la pantalla

Es el modo de todos los días y el de una máquina de integración. El navegador no se abre, el teléfono virtual no tiene ventana y el iPhone no muestra el simulador.

Mostrando la pantalla

Sirve cuando una persona quiere ver qué está pasando. Se abre el navegador, la ventana de la computadora, el teléfono Android o la ventana del iPhone.

En la computadora, aunque la ventana esté visible, los pasos no se dibujan con el mouse: la prueba se los pide directo a la app.
